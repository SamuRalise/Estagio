# Automação de Redes - Estágio Datacom

Repositório contendo **scripts e ferramentas de automação desenvolvidos durante o estágio na Datacom**, focados em **redes de computadores** e **otimização de tarefas operacionais do dia a dia**.

O objetivo deste repositório é organizar soluções que auxiliam em atividades como **configuração de dispositivos, coleta de informações de rede, validações operacionais e automação de processos repetitivos**.

---

## Objetivo

Centralizar scripts utilizados para:

* Automação de tarefas operacionais de rede
* Coleta e análise de informações de equipamentos
* Execução de comandos em múltiplos dispositivos
* Auxílio em rotinas de troubleshooting
* Redução de atividades manuais repetitivas

---

## Tecnologias Utilizadas

Dependendo da automação desenvolvida, os scripts podem utilizar:

* Python
* Bash / Shell Script
* Protocolos de rede (SSH, Telnet, SNMP, etc.)
* Bibliotecas de automação de redes

---

---

## Exemplos de Automação

Alguns tipos de automação que podem ser incluídos neste repositório:

* Execução de comandos em múltiplos roteadores ou switches
* Coleta de informações de interfaces
* Verificação de estado de protocolos de rede
* Automação de tarefas de monitoramento
* Scripts de apoio para troubleshooting

---

## Observação

Este repositório contém **apenas scripts genéricos de automação**.
Nenhuma informação sensível, credenciais ou dados internos da empresa são incluídos.
